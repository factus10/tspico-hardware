# TS-Pico v3 KiCad project

Status: Phase 3 (layout) started 2026-09-16: all 157 footprints are placed from the netlist with GND (In1.Cu) and +3V3 (In2.Cu) planes, DRC clean apart from the unrouted connections. Routing is next and is done interactively in KiCad (no autorouter available here). Schematic: all eight sheets drawn, ERC clean, LCSC numbers on every orderable part. The board file holds only the outline, the edge connector, mounting holes and fiducials; layout (Phase 3) has not started.

Sheets are generated by `scripts/gen_<sheet>.py` on top of `scripts/schlib.py`, netlist-style (labels on every pin, no wires). Regenerating a sheet overwrites hand edits, so once a sheet is being edited in KiCad, retire its generator. Spec: [../docs/v3-architecture.md](../docs/v3-architecture.md).

## Files

| File | Purpose |
|---|---|
| `tspico-v3.kicad_pro` | Project. Design rules are JLCPCB 4-layer capable but conservative: 0.127 mm min clearance and track, 0.45/0.2 mm min via, 0.3 mm copper-to-edge. Net classes: Default 0.2 mm track / 0.6-0.3 via, Power 0.5 mm / 0.8-0.4. |
| `tspico-v3.kicad_sch` | Root sheet with eight hierarchical sheets: `interface`, `memory`, `mcu`, `power`, `storage_display`, `wifi`, `audio`, `joystick`. |
| `tspico-v3.kicad_pcb` | 4-layer board (F.Cu, In1 GND, In2 PWR, B.Cu), 1.6 mm, ENIG. Outline and connector generated by `scripts/gen_board.py`. |
| `lib/tspico.pretty/TS2068_EdgeConnector_2x32.kicad_mod` | The 2068 edge connector (generated). |
| `lib/tspico.kicad_sym` | Project symbols (empty so far; ESP32-C3 module and anything not in the stock library go here). |
| `scripts/gen_board.py` | Regenerates the edge-connector footprint and the bare board skeleton (outline, connector, holes, fiducials). Called by `gen_layout.py`. |
| `scripts/gen_layout.py` | Builds the placed board: exports the netlist, loads every footprint from the KiCad or project library, assigns nets, places parts from its `P` table, adds the GND and +3V3 zones. | `scripts/check.sh` | `kicad-cli` ERC and DRC. |
| `scripts/schlib.py`, `scripts/gen_edge_symbol.py`, `scripts/gen_interface.py`, `scripts/gen_memory.py`, `scripts/gen_mcu.py`, `scripts/gen_power.py`, `scripts/gen_storage_display.py`, `scripts/gen_wifi.py`, `scripts/gen_audio.py`, `scripts/gen_joystick.py` | Schematic generators (see above). |

## Edge connector geometry

Measured from the v2.2 fab Gerbers (`../old/tsPico2_2Fab/Gerber/tsPico.GTL`, `.GBL`, `.Outline`):

| Item | Value |
|---|---|
| Board | 130.00 x 100.00 mm, 1.6 mm |
| Body | 130.00 x 91.75 mm |
| Tongue | 83.66 mm wide, 8.25 mm deep, left edge 18.48 mm from the board's left edge, 1.0 mm corner chamfers |
| Positions | 32 at 2.54 mm pitch, 31 fingers per side |
| Keying slot | position 6, 2.03 mm wide, 8.26 mm deep |
| Fingers | 1.651 x 8.255 mm (65 x 325 mil), first finger centre 2.52 mm from the tongue's left edge, bottom edge 0.32 mm above the tongue edge |

Pad names are `A1`..`A32` on F.Cu and `B1`..`B32` on B.Cu (no A6/B6), following the TS2068 Technical Manual table 2.4.1-1. Position 1 is at the left when the board is viewed from the top with the connector at the bottom.

**Assumption to verify before ordering:** side A (GND, EAR, D7, ..., SOUND) is on the top (component) side and side B (+15V, +5V, address bus, video) on the bottom. This matches how the v2.2 layout routes +5V (bottom trace from the fourth finger), but confirm it against the v2.2 CircuitStudio PCB or a physical card.

Fab notes for the fingers: hard gold over the fingers if the fab offers it (ENIG otherwise), 30 degree bevel on the tongue edge, no copper within 0.3 mm of the slot.

## Regenerating the BOM

```bash
cd hardware
KC=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli
$KC sch export bom --output bom/tspico-v3-jlcpcb-bom.csv --fields "Value,Reference,Footprint,LCSC" --labels "Comment,Designator,Footprint,LCSC Part #" --group-by "Value,Footprint" --exclude-dnp tspico-v3.kicad_sch
```

Part-number decisions forced by LCSC stock: 74HC273PW for the CTL register (no 74LVC273 stocked; HC is fine at 3.3 V), 74LVC139PW (non-A), TI parts for the LVC04/08/126/574/1G86, 33 R instead of 27 R on USB D+/D- (basic part), XKB TS-1187A-B-A-B tactile switches (basic), Panasonic 6SVPC220MV polymer for the bulk and WiFi caps. The 3.3 uH inductor (Sunlord SWPA252012S3R3MT) has no confirmed LCSC number yet.

## Layout notes (placement pass)

- Connector edges: USB-C (J1) and OLED header (J3) on the top edge, ESP32-C3 antenna over the top-left edge, micro SD (J2) on the left edge, DE-9 (J5) and 3.5 mm jack (J4) on the right edge, buttons along the lower right.
- Z80 transceivers U1-U4 sit directly above the fingers; gating and muxes above them; registers above those; RP2350B cluster in the centre with the crystal, QSPI flash and PSRAM around it.
- Verified in the 3D render: USB-C opening faces outward, D-sub face protrudes past the right edge, SD card exits to the left, antenna overhangs.
- Before ordering: check the D-sub footprint against the CONNFLY DS1037 drawing, confirm the SD socket's card-detect switch polarity, and add 3D models if wanted for the jack and the TS-1187A switches (KiCad ships none for them).
